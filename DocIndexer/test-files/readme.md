# Введение
Это документация проекта. Он написан на C# и использует современные подходы к разработке.
Проект предназначен для индексации документов и семантического поиска по ним.

# Архитектура
Проект использует чистую архитектуру с разделением на слои. Основные компоненты:
- Модели данных
- Сервисы индексации
- Хранилище векторов
- Стратегии чанкинга

Каждый слой отвечает за свою область ответственности и может быть легко заменен.

# API
REST API предоставляет endpoints для работы с данными. Основные методы:
- POST /index — запуск индексации
- GET /search — поиск по индексу
- DELETE /clear — очистка индекса

API документирован с помощью OpenAPI/Swagger.

# Установка и настройка
Для установки выполните следующие шаги:
1. Установите .NET 10 SDK
2. Склонируйте репозиторий
3. Выполните dotnet restore
4. Настройте подключение к Ollama

# Производительность
Система показывает высокую производительность при индексации больших объемов данных.
Оптимизации включают:
- Пакетная обработка эмбеддингов
- Кэширование результатов
- Асинхронные операции
